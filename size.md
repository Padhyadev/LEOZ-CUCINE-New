# LEOZ CUCINE — Image Specifications & Dimension Guide (`size.md`)

This guide provides exact aspect ratios, display dimensions, recommended upload resolutions, and file format recommendations for all image assets used across the **LEOZ CUCINE** platform, organized page-by-page and section-by-section.

---

## 🎨 Asset Optimization Standards

- **Formats**: `.webp` (Recommended for web performance) or `.jpg` / `.png`
- **Color Space**: sRGB
- **Quality**: 85%–90% compression for WebP/JPEG
- **DPI**: 72 DPI (Web Standard)
- **Max File Size**: 
  - Fullscreen Hero Banners: **< 350 KB**
  - Section Banners / Large Displays: **< 200 KB**
  - Cards & Grid Thumbnails: **< 120 KB**
